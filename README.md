# 📚 Data Structures & Algorithms with Java

A comprehensive collection of **Data Structures and Algorithms (DSA)** implemented in **Java**, covering fundamental to advanced concepts. This repository is designed for **interview preparation, concept clarity, and hands-on practice**.

- Binary Search Tree (BST)
- AVL Tree (Self-Balancing BST)
- Segment Tree (Range Sum Query)

### 🔗 Linked List
- Custom Linked List Implementation

### 🔁 Graphs
- Breadth First Search (BFS)
- Depth First Search (DFS)

### 📦 Advanced Data Structures
- Disjoint Set (Union-Find)
- LRU Cache Implementation
- Priority Queue using Heap

### 📊 Stack & Queue
- Stack & Queue Visualizer
