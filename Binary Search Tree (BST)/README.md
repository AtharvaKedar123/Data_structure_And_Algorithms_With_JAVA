# Binary Search Tree (BST)

## 📌 Concept
A tree where left child < root < right child.

## 🚀 Why it is used
Efficient searching, insertion, and deletion compared to linear structures.

## ⏱ Time Complexity
- Average: O(log n)
- Worst: O(n)

## 🧠 Key Idea
Recursive traversal based on value comparison.

## 💻 Implementation Details
Supports insert, delete, search, and traversal (inorder, preorder, postorder).

## 📍 Real-World Use Case
- Searching systems
- Sorted data storage
